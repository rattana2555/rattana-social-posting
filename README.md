# Rattana Social Posting v1.0

โพสต์ครั้งเดียว ลงได้หลายแพลตฟอร์ม หลายบัญชีพร้อมกัน

| แพลตฟอร์ม | ปลายทาง | รองรับ |
|---|---|---|
| Facebook | เพจ (หลายเพจ / หลายบัญชี FB) | ข้อความ, รูป 1–10 รูป (อัลบั้ม), วิดีโอ |
| TikTok | บัญชี TikTok (หลายบัญชี) | วิดีโอ — โพสต์ทันที หรือส่งเป็นดราฟต์เข้าแอป |
| LINE OA | Broadcast ถึงเพื่อนทุกคน (หลาย OA) | ข้อความ, รูป (เกิน 4 รูปจะส่งเป็นอัลบั้มเลื่อน), วิดีโอ mp4 ≤ 200MB |

มีระบบ **ตั้งเวลาโพสต์**, **ปรับข้อความแยกตามแพลตฟอร์ม**, **ดูผลแยกทีละบัญชี** และ **กดลองใหม่เฉพาะบัญชีที่ล้มเหลว**

---

## เริ่มใช้งาน

1. ดับเบิลคลิก `start.bat` (ครั้งแรกจะติดตั้ง package ให้อัตโนมัติ)
2. เบราว์เซอร์จะเปิด http://localhost:3210
3. ไปที่แท็บ **⚙️ ตั้งค่า** ใส่ App ID / Secret ของ Facebook และ TikTok
4. ไปที่แท็บ **👥 บัญชี** เชื่อมต่อบัญชีต่าง ๆ
5. แท็บ **✍️ สร้างโพสต์** → เขียนข้อความ แนบสื่อ เลือกบัญชี → โพสต์

> ⚠️ ต้องเปิดหน้าต่าง `start.bat` ค้างไว้ — ถ้าปิด โพสต์ที่ตั้งเวลาไว้จะไม่ทำงาน
> (ถ้าเปิดแอปกลับมาช้ากว่าเวลาที่ตั้งไม่เกิน 1 ชั่วโมงจะโพสต์ให้ทันที ถ้าเกินจะขึ้นสถานะ "พลาดเวลา" ให้กดโพสต์เอง)

### ติดตั้ง cloudflared (จำเป็นสำหรับส่งรูป/วิดีโอทาง LINE)

LINE ต้องดึงรูป/วิดีโอจาก URL สาธารณะแบบ HTTPS แอปจึงเปิด Cloudflare Tunnel ชั่วคราวให้อัตโนมัติ
(เปิดให้เข้าถึงได้เฉพาะไฟล์สื่อที่อัปโหลด ชื่อไฟล์เป็นรหัสสุ่ม — หน้าแอปและ token ไม่ถูกเปิดออกไป)

```
winget install Cloudflare.cloudflared
```

ติดตั้งเสร็จแล้วปิด-เปิด `start.bat` ใหม่ ถ้าไม่ติดตั้ง LINE จะส่งได้เฉพาะข้อความ

`ffmpeg` (มีในเครื่องแล้ว) ใช้สร้างภาพตัวอย่างและแปลงไฟล์ให้ตรงสเปก LINE

## 1. Facebook (มี App แล้ว)

1. https://developers.facebook.com/apps → เลือกแอป
2. **App settings → Basic** → คัดลอก **App ID** และ **App Secret** ไปใส่ในแท็บตั้งค่า
3. เพิ่ม Product **Facebook Login** (หรือ Facebook Login for Business) → **Settings** →
   ใส่ **Valid OAuth Redirect URIs**: `http://localhost:3210/auth/facebook/callback`
4. ในแอป แท็บบัญชี → **เชื่อมต่อด้วย Facebook** → เลือกเพจที่ต้องการ → ระบบจะดึงทุกเพจมาให้

หมายเหตุ
- แอปในโหมด **Development** โพสต์ได้เฉพาะเพจของคนที่มีบทบาทในแอป (Admin/Developer/Tester) — ถ้าเป็นเพจของตัวเอง/บริษัทใช้ได้เลย
  ถ้าจะให้คนนอกใช้ ต้องส่ง App Review ขอสิทธิ์ `pages_manage_posts`
- Token ของเพจที่ได้มาเป็นแบบไม่หมดอายุ (เว้นแต่เปลี่ยนรหัสผ่าน / ถอดสิทธิ์แอป) — ถ้าขึ้น error code 190 ให้กดเชื่อมต่อใหม่
- ล็อกอินซ้ำด้วยบัญชี Facebook คนอื่นเพื่อเพิ่มเพจของคนนั้นได้

## 2. TikTok (ยังไม่มี — ต้องสมัคร)

1. สมัคร https://developers.tiktok.com → **Manage apps → Connect an app**
2. กรอกข้อมูลแอป (ชื่อ, ไอคอน, หมวดหมู่, ลิงก์ Terms/Privacy Policy)
3. **Add products**:
   - **Login Kit** → Platform เลือก **Desktop** → Redirect URI: `http://localhost:3210/auth/tiktok/callback`
   - **Content Posting API** → เปิด **Direct Post**
4. **Scopes**: `user.info.basic`, `video.upload`, `video.publish`
5. คัดลอก **Client Key** และ **Client Secret** ไปใส่ในแท็บตั้งค่า
6. ระหว่างยังไม่ผ่านรีวิว ให้ใช้ **Sandbox** และเพิ่มบัญชี TikTok ของคุณเป็น **Target users**
7. แท็บบัญชี → **เชื่อมต่อบัญชี TikTok** (เพิ่มบัญชีถัดไป: ออกจากระบบ tiktok.com ในเบราว์เซอร์ก่อน)

ข้อจำกัดของ TikTok
- แอปที่ **ยังไม่ผ่าน Audit** โพสต์ได้แค่แบบ **"เฉพาะฉัน" (SELF_ONLY)** — ถ้าต้องการโพสต์สาธารณะอัตโนมัติ ต้องส่ง Audit ที่หน้า Content Posting API
  ระหว่างรอ ให้เลือก **"ส่งเข้าแอป TikTok เป็นดราฟต์"** แล้วไปกดโพสต์ในมือถือเอง
- รองรับเฉพาะวิดีโอ (การโพสต์รูปของ TikTok ต้องยืนยันโดเมน — ยังไม่รองรับในเวอร์ชันนี้)
- ต้องเชื่อมต่อบัญชีใหม่ทุก ~1 ปี (แอปแสดงวันหมดอายุไว้ในแท็บบัญชี)

## 3. LINE OA (มีแล้ว)

1. https://developers.line.biz → เลือก Provider → Channel แบบ **Messaging API** ของแต่ละ OA
2. แท็บ **Messaging API** → **Channel access token (long-lived)** → **Issue** → คัดลอก
3. แท็บบัญชีในแอป → **+ เพิ่ม LINE OA** → วาง token (ทำซ้ำทีละ OA)

หมายเหตุ
- โพสต์ไป LINE = **Broadcast ถึงเพื่อนทุกคนของ OA** ยกเลิกไม่ได้ และนับโควต้าข้อความรายเดือน (กดปุ่ม 📊 ดูโควต้าที่เหลือ)
- LINE อาจดึงรูปจาก URL อีกครั้งภายหลัง แนะนำเปิดแอปค้างไว้สักพักหลัง Broadcast
  ถ้ามีโดเมนถาวร (เช่น Cloudflare named tunnel ชี้มาที่ port 3211) ใส่ใน **Public Media URL** ที่แท็บตั้งค่าได้

## ความปลอดภัย

- แอปเปิดรับเฉพาะเครื่องนี้ (`localhost`) — เครื่องอื่นในเน็ตเวิร์กเข้าไม่ได้
- Token และไฟล์ที่อัปโหลดเก็บใน `data/` — **ห้ามส่งโฟลเดอร์นี้ให้ใคร**
- เก็บโค้ดขึ้น GitHub ได้ (`.gitignore` กันโฟลเดอร์ `data/` ไว้แล้ว) แต่ GitHub Pages รันแอปนี้ไม่ได้ เพราะต้องมีเซิร์ฟเวอร์เก็บ token และเรียก API ของ LINE

## โครงสร้างไฟล์

```
server.js            เซิร์ฟเวอร์หลัก + API + ตัวตั้งเวลา
lib/facebook.js      Graph API (เพจ, รูป, อัลบั้ม, วิดีโอ)
lib/tiktok.js        Login Kit (PKCE) + Content Posting API
lib/line.js          Messaging API broadcast
lib/publisher.js     กระจายโพสต์ไปแต่ละบัญชี เก็บผลลัพธ์
lib/tunnel.js        Cloudflare quick tunnel สำหรับสื่อของ LINE
lib/media.js         ffmpeg (ภาพตัวอย่าง / แปลงไฟล์)
public/index.html    หน้าเว็บทั้งหมด
data/                ฐานข้อมูล (db.json) + ไฟล์อัปโหลด — สร้างอัตโนมัติ
```

เปลี่ยน port ได้ด้วย environment variable `PORT` (ค่าเริ่มต้น 3210) และ `MEDIA_PORT` (3211)
— ถ้าเปลี่ยน `PORT` ต้องแก้ Redirect URI ใน Facebook / TikTok ให้ตรงด้วย
